# BookStore

A full-stack bookstore web application built entirely with Vue.js for both the frontend and backend. The app enables users to browse, search, and manage a collection of books with a clean, modern interface.

## Features

- Browse and search books by title, author, or genre
- Add, edit, and delete books (CRUD operations)
- Responsive design for desktop and mobile
- Vue.js-powered SPA with seamless navigation
- RESTful API backend

## Tech Stack

- **Frontend:** Vue.js, Vue Router, Vuex
- **Backend:** Vue.js (server-side)
- **Styling:** CSS3

## Getting Started

### Prerequisites

- Node.js (v14+)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Rajshingade7/BookStore.git
   cd BookStore
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run serve
   ```

4. Open [http://localhost:8080](http://localhost:8080) in your browser.
